# tg-notify

Короткий CLI: отправить текстовое уведомление в Telegram-чат одним вызовом. Без зависимостей — только стандартная библиотека (`urllib`), Python ≥ 3.11.

## Установка

```bash
pip install -e .
```

(или через `uv`: `uv sync`)

## Настройка

Нужен бот-токен и id чата. Три способа задать, приоритет сверху вниз:

1. Флаги CLI (`--chat`)
2. Переменные окружения: `TG_TOKEN`, `TG_CHAT`
3. Файл `.env` в текущем каталоге

```bash
# .env
TG_TOKEN=123456:ABC...
TG_CHAT=-1001234567890
```

Токен создаёте через [@BotFather](https://t.me/BotFather), id чата — через [@userinfobot](https://t.me/userinfobot) (для каналов/групп — отрицательный id).

## Использование

```bash
# текст из аргумента
tg-notify "✅ сборка прошла"

# текст из файла
tg-notify --file report.txt

# без звука
tg-notify --silent "фоновое событие"

# обрезать длинный текст (по умолчанию 500 символов)
tg-notify --truncate 200 --file log.txt

# другой чат
tg-notify --chat -1009876543210 "привет"
```

При успехе выводит `✅ sent`, при ошибке — `❌ not sent: <причина>` и код возврата 1.

## Формат сообщений

Соблюдайте шаблон из `templates/notify.md`:

```
<иконка> <что> · <где>
<деталь 1>
<деталь 2>
```

≤ 4 строки, ≤ 200 символов, без приветствий. Иконки: ✅ успех · ❌ фейл · ⚠️ внимание · ℹ️ инфо.

Пример для скриптов:

```bash
tg-notify --file <(printf '✅ deploy · api\nv2.3.1\n12 сек') --truncate 0
```
